# COVID-19 Global Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **COVID-19 Global Analysis Dashboard** built using **Tableau**, with data preprocessing performed in **Python**.

The goal of this project is to analyze global COVID-19 trends and provide meaningful insights through clean and interactive visualizations.


🔧 Data Cleaning (Python)

The dataset was processed using Python to ensure accuracy and usability:

* Handled missing and null values
* Created a **Fatality Rate** column
* Aggregated data at country level
* Cleaned and structured dataset for visualization

📈 Dashboard Features (Tableau)

* KPI Cards:

  * Total Cases
  * Total Deaths
  * Fatality Rate

* 🌍 Interactive World Map

* 📊 Top N Countries (Dynamic Parameter)

* 🌐 Continent-based Filtering

* 📉 Population-adjusted insights


# Key Insight

The United States has the highest number of total cases, while several highly populated countries show relatively lower infection rates, highlighting the importance of **normalized metrics**.
